# Knight Club visual system

An evening player practices at a desk with low ambient light; dark charcoal surfaces reduce glare and a moss-green board holds attention.

Use a restrained strategy: layered neutral charcoal, white ink, muted gray-green secondary text, and the user's chosen green accent. The requested green identity takes precedence over the randomly generated palette seed.

System sans-serif for readable interface labels. Monospaced tabular numerals for clocks and evaluations. Compact type hierarchy, generous board space, 8–12px panel radii, full-pill status badges. Desktop uses a left navigation rail and a board with a companion panel; mobile folds navigation and stacks panels. Motion communicates selection, thinking, and piece movement; reduced motion removes transitions.
